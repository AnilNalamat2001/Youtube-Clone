# YouTube Clone

A responsive YouTube-inspired web interface built using HTML and CSS. The project recreates the core layout and visual structure of a modern video streaming platform.

## 🚀 Features

* Responsive video browsing layout
* Navigation sidebar
* Video thumbnail grid
* Search bar interface
* Video information cards
* Channel information
* Responsive design for different screen sizes

## 🛠️ Technologies Used

* HTML5
* CSS3
* Responsive Web Design

## 🎯 Project Purpose

This project was built to strengthen frontend development fundamentals and practice creating responsive web interfaces from scratch.

It demonstrates:

* Semantic HTML
* CSS layouts
* Flexbox
* Grid
* Responsive design
* Component-like UI structure
* Web page styling
